# Sales Performance & Forecasting Analysis

## Project Overview
This project analyzes sales performance, profitability, regional performance, discount impact, and sales forecasting using Python.

The goal is to support business decision-making from a Data Analyst / Business Controller perspective.

## Business Questions
- How are sales developing over time?
- Which regions and categories generate the most sales?
- Which product areas are less profitable?
- How does discounting affect profitability?
- What does the sales trend suggest for future planning?

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Key Analysis
- KPI overview: sales, profit, profit margin
- Monthly sales trend
- Sales by region
- Profit by category
- Loss-making sub-categories
- Discount vs. profit analysis
- Simple sales forecasting model

## Key Insights
- Sales performance varies significantly across regions.
- Some sub-categories generate losses despite sales activity.
- Higher discounts appear to reduce profitability.
- Forecasting can support planning and budgeting decisions.
